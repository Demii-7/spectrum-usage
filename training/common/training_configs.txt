# Integrated Pipeline Runbook — DSwinLSTM-I, VanillaLSTM, ConvLSTM, TimeRAN & Residual Variants
# ===========================================================================================
# For every run, update these fields in training/common/config.yaml:
#   1. data.representation     — "2d" for sequence CSVs, "4d" for spatial maps
#   2. data.files              — list of {path, partition} entries
#   3. data.map                — required for 4d (name, locations)
#   4. data.chunks             — frequency range
#   5. training.model_name     — one of the SUPPORTED_MODELS
#   6. model_name.model.*      — prediction_horizon must match windowing.horizons
#   7. model_name.train.*      — training hyperparams (batch_size, epochs, lr, ...)
#
# Then run:
#   ./.venv/bin/python training/common/train_integrated.py
#   ./.venv/bin/python training/common/evaluation_integrated.py
#
# Artifacts appear under runs/<name>/ per RUNS.md.
# =============================================================================
