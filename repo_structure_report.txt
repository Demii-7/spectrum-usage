1. TOP-LEVEL FILES AND DIRECTORIES
--------------------------------------------------------------------------------

  .gitignore
      Ignores: __pycache__/, *.pyc, *.pyo, .venv/, *.pt, *.zip, *.pdf,
      training/DeepSPred/FM-S*, *.xls

  predictions.csv
      Example predictions file at repo root (6 rows, 250 columns of dBm
      values, comma-separated). One row per predicted time step, one column
      per frequency bin.

  ResultsCC1Feb2022_SigMF.zip  (~19 GB, gitignored via *.zip)
  ResultsCC2Feb2022_SigMF.zip  (~21 GB, gitignored via *.zip)
  ResultsLW1Feb2022_SigMF.zip  (~12 GB, gitignored via *.zip)
      Raw AERPAW SigMF archives from Feb 2022 field measurements.
      Extracted and processed by training/build_training_csv.py.

  checkpoints/
      Contains best_autoencoder.pt -- shared autoencoder checkpoint used
      by TSS-LCD stage 1 as pretrained latent autoencoder weights.

  data/
      Contains 16 CSV and NPZ files from POWDER testbed field measurements
      (two sites: guesthouse, humanities; two bands: 600-800 MHz,
      2400-2600 MHz). Includes temporal test split files for evaluation.

  evaluation/
      Data collection and processing scripts. Full description in Section 5.

  extern/
      Forked copy of thuml/Autoformer repository (NeurIPS 2021). Contains
      the original Autoformer model code, layers (AutoCorrelation,
      Encoder/Decoder, Embed), experiment runners, data providers, and
      utility scripts. Also includes the Autoformer-CSA paper PDF.
      Used as reference backbone by training/Autoformer-CSA/.

  models/
      Contains only README.md (placeholder: "models that we train on the
      spectrum usage prediction task"). Model source code lives under
      training/ instead.

  plots/
      Contains 6 files: figure9 ground-truth spectrograms (5 PNGs) and a
      README.md placeholder. Generated visualizations for paper
      reproduction.

  results/
      Contains only README.md (placeholder: "evaluation results for all
      of the models") plus an .ipynb_checkpoints artifact.

  training/
      All model implementations, training data, and pipeline scripts.
      Detailed in Section 2 below.

--------------------------------------------------------------------------------

2. training/ DIRECTORY (ROOT)
--------------------------------------------------------------------------------

  training/README.md  (555 lines)
      Comprehensive documentation of the training data pipeline:
      downloading AERPAW SigMF archives from Dryad, extracting 250-bin
      per-node slices from raw bin offsets (CC1=21000, CC2=33250,
      LW1=27500), per-minute averaging, merging into a single 750-column
      CSV. Documents the reverse-engineering methodology used to discover
      the bin offsets.

  training/build_training_csv.py
      Main preprocessing script. Reads SigMF zip archives, extracts 250
      float32 bins per node at the documented offsets, converts to linear
      power, averages per minute, and merges all 3 nodes horizontally into
      a single 750-column CSV (no header, 6 decimal places).

--------------------------------------------------------------------------------

3. training/data/
--------------------------------------------------------------------------------

  download_dryad.py
      Downloads the 3 AERPAW SigMF zip archives from Dryad. Handles the
      Anubis proof-of-work WAF challenge using multiprocessing SHA256
      nonce brute-force. Supports --dir for custom output path.

  merged_power_data_sub6GHz_avg_per_minute.csv
      PRIMARY DATASET. 6839 rows x 750 columns, per-minute averaged PSD
      in dBm. No header. Columns 0-249 = CC1, 250-499 = CC2, 500-749 =
      LW1. Input to all model training scripts.

  merged_power_data_sub6GHz_avg_per_minute.csv.json
      JSON manifest recording processing metadata: creation time, row
      count (6839), per-node bin offsets, node labels.

  merged_power_data_sub6GHz_avg_per_minute_87_336.csv
      Alternative merged CSV using originally-claimed 87-336 MHz band
      offsets (for comparison/reproduction).

  cc2_smoke_test.csv
      CC2-only subset (first 2000 rows, 250 columns). Used for smoke
      tests across all models.

  recon_smoothed_norm.csv
  recon_smoothed_db.csv
  reconstructed_repo_csv.csv
      Reconstructed/smoothed/normalized versions of the dataset. Used
      for comparison with the original TSS-LCD repository CSV format.

  4.1 training/Autoformer-CSA/
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  Model description: Autoformer with Channel-Spatial Attention Module
  (CSAM). Adaptation of Pan et al., IEEE WCL 2023. Uses the upstream
  Autoformer backbone (from extern/) enhanced with CSAM blocks for
  channel-wise and spatial attention.

  Supporting files:
    __init__.py          Package marker.
    config.yaml          Hyperparameters: data paths, model dims (d_model=512,
                         d_ff=2048, n_heads=8, e_layers=2, d_layers=1),
                         architecture flags (use_csam=true,
                         preserve_original_autoformer=false), training
                         settings (lr=0.0001, batch_size=32).
    dataset.py           AERPAWDataset. Loads CSV or NPZ interpolated maps,
                         applies chronological splits, z-score normalization
                         (fit on train only), sliding windows.
    model.py             ChannelAttention, SpatialAttention, CSAM,
                         EncoderLayerCSA, DecoderLayerCSA, AutoformerCSA.
                         Imports upstream Autoformer backbone from extern/.
    train.py             Training loop with MSE loss, Adam, early stopping.
    evaluate.py          Standalone evaluation on test split. Loads checkpoint,
                         computes RMSE/MAE/R2, exports predictions, generates
                         spectrogram plots.
    inference.py         Forward pass on new CSV or NPZ data.
    utils.py             Metrics computation, denormalization, plotting,
                         early stopping class.
    README.md  (759 l.)  Documents CSAM architecture, Autoformer backbone,
                         training pipeline, full config reference.

  Generated artifacts:
    checkpoints/         best_model.pt, last_model.pt, config.yaml (copy),
                         training_log.json.
    evaluation/          metrics.json, predictions.csv, ground_truth.csv,
                         spectrogram_CC2.png, error_analysis.png.
    smoke_test/          config.yaml, report.txt, checkpoints/, evaluation/.
    smoke_test_map/      config.yaml, checkpoints/ (map-mode smoke test).

    evaluate.py          Evaluation in both RGB space (MSE/RMSE/MAE/R2/PSNR/

  4.7 training/TSS-LCD/
  ~~~~~~~~~~~~~~~~~~~~~

  Model description: Temporal-Spectral-Spatial Latent Conditional
  Diffusion. Adaptation of Cheng et al., IEEE TCCN 2026. Three-stage
  training: (1) Conv2D autoencoder (LSE/LSD), (2) TSS-CC condition
  branches (TemFE, SpeFE, SpaFE with cross-attention fusion), (3) NEN
  noise estimation (1D Conv U-Net with LCD-SP). Supports continuous
  masking with configurable length/shared-gap/multiple-gap modes.

  Supporting files:
    __init__.py          Package marker.
    config.yaml          T_in=50, T_out=10, latent_dim=32, hidden_dim=256,
                         diffusion_steps=1000, autoencoder_activation=relu,
                         nen_activation=relu, nen_normalization=batchnorm,
                         condition_strategy=concat.
    dataset.py           TSSLCDDataset: CSV loading, reshape to (T,L,F),
                         chronological split, sliding windows, missing
                         entry simulation (random/continuous masking).
    model.py             PositionalEncoding, MultiHeadSelfAttention,
                         TemFE/SpeFE/SpaFE, CrossAttentionFFM, LSE (Conv2d),
                         LSD (ConvTranspose2d), NEN (Conv1D U-Net),
                         DiffusionModel (cosine schedule).
    train_autoencoder.py Stage 1: LSE+LSD autoencoder pretraining (MSE).
    train_tss_condition.py Stage 2: TSS-CC conditioning (frozen AE,
                         projection_to_latent objective).
    train_diffusion.py   Stage 3: NEN noise estimation (frozen
                         LSE/LSD/TSS-CC).
    evaluate.py          Full evaluation: X -> TSS-CC -> reverse diffusion
                         -> predictions. Per-horizon/per-node/per-frequency
                         metrics. Metrics in nested format.
    inference.py         Standalone online inference from incomplete obs.
    utils.py             Normalization, metrics, checkpointing, config.
    report.txt           Training/evaluation summary.
    README.md  (483 l.)  Three-stage pipeline, TSS-CC branches, LCD-SP,
                         paper-faithful vs repo differences.

  Generated artifacts:
    checkpoints/         best_autoencoder.pt, best_tss_condition.pt,

================================================================================
PART 2: INTEGRATE BRANCH
================================================================================

  NOTE: The integrate branch represents a major refactoring of main.
  Instead of standalone self-contained model directories, it introduces
  a shared pipeline under training/common/ and replaces individual
  train.py scripts with unified train_integrated.py runners that all
  consume the same shared configuration and utilities.

  Several model source files from main were DELETED on integrate (their
  generated checkpoints and evaluation artifacts remain). The focus is
  on 4 models with integrated runners (ConvLSTM, STS-PredNet, TSS-LCD,
  TimeRAN) plus a new LinearAutoRegressive baseline. Autoformer-CSA,
  DSwinLSTM-I, DeepSPred, and VanillaLSTM had their source files removed.

2. training/common/ -- SHARED PIPELINE PACKAGE
--------------------------------------------------------------------------------

  This package is the core of the integrate branch architecture. It
  provides shared utilities consumed by all train_integrated.py runners.

  __init__.py
      Package marker. Docstring: "Shared training utilities for spectrum
      prediction models."

  config.yaml
      Single shared configuration file for all models. Sections:
      - data: chunk specs (600-800, 2400-2600, 3500-3700 MHz) including
        site, col_start, col_end, chunk_name
      - windowing: lookback=60, horizons=[1,5,15,60]
      - normalization: method=zscore
      - ConvLSTM: hidden_dim, kernel_size, lr, batch_size, epochs, etc.
      - STS-PredNet: num_layers, hidden_dim, lc, lp, lr, etc.
      - TimeRAN: checkpoint_size, T_in, T_out, freeze_backbone, etc.
      - TSS-LCD: T_in, T_out, latent_dim, hidden_dim, diffusion_steps, etc.

  config.py
      YAML config loader with validation. Resolves relative paths against
      repo root. Checks for required sections (data, windowing,
      preprocessing, outputs). Returns structured Config object.

  data.py
      Shared data loader and preprocessor. Key functions:
      - load_chunk(): loads a frequency chunk from AERPAW CSV by node
        columns, returns numpy array
      - model_matrix_to_convlstm_frames(): reshapes flat features into
        (T, C, H, W) for ConvLSTM
      - clean_interpolated_map(): NaN imputation for 4D map arrays

  metrics.py
      Denormalization and error computation. Functions:
      - denormalize(): reverses z-score scaling
      - metric_values_dbm(): computes per-sample errors in dBm
      - absolute_and_squared_errors_dbm(): raw error arrays for aggregation

  results.py
      Output and results management. Functions:
      - load_band_definitions(): reads band definitions from config
      - create_output_directories(): ensures results tree exists
      - append_aggregate_metrics_row(), append_per_frequency_metrics_row(),
        append_per_band_metrics_row(): write to CSV

  windowing.py
      Target and history window computation. Functions:
      - target_rows_for(): computes target row indices for a given horizon
      - lagged_matrix(): builds lagged feature matrix for autoregression
      - aligned_history_matrix(): builds aligned history matrix for
        lookback-based models
      - horizon_index_selection(): selects specific horizon indices

  aerpaw_loader.py
      AERPAW CSV loader. Interpolates missing values (forward-fill then
      linear interpolation), splits chronologically (last 2 days as test),
      optionally normalizes to zero-mean unit-variance.

  assemble_results.py
      Combines aggregate, per-frequency, and per-band metrics from all
      model output directories into unified CSVs. Writes a markdown
      summary report with best-model tables.

3. INTEGRATED MODEL RUNNERS (train_integrated.py)
--------------------------------------------------------------------------------

  3.1 training/ConvLSTM/train_integrated.py
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  Integrated ConvLSTM runner. Workflow:
    1. Parse --config (defaults to training/common/config.yaml)
    2. Load chunk specs from config.data.chunks
    3. For each chunk: load data via load_chunk(), reshape via
       model_matrix_to_convlstm_frames(), train ConvLSTM model
    4. Evaluate all configured horizons (1, 5, 15, 60)
    5. Write aggregate/per-frequency/per-band metrics to
       training/results/ConvLSTM/ via results.py helpers

7. INTEGRATE BRANCH SUMMARY
--------------------------------------------------------------------------------

  Branch purpose:
      Refactor the standalone model implementations from main into a
      shared pipeline architecture. Instead of each model having its own
      train.py, dataset.py, config.yaml, etc., all models share:
        - training/common/config.yaml (single config)
        - training/common/data.py (shared data loading)
        - training/common/metrics.py (shared metrics)
        - training/common/results.py (shared output format)
        - training/common/windowing.py (shared window logic)

  Current integrated models (4):
      ConvLSTM, STS-PredNet, TSS-LCD, TimeRAN
      + LinearAutoRegressive baseline

  Models removed from pipeline (4):
      Autoformer-CSA, DSwinLSTM-I, DeepSPred, VanillaLSTM
      (source files deleted; checkpoints/artifacts remain)

  Pipeline workflow:
      1. training/common/config.yaml defines data chunks (frequency bands
         and node columns), windowing (lookback/horizons), and model-
         specific hyperparameters.
      2. Each train_integrated.py iterates over chunks, calls
         load_chunk() for data, trains per-chunk, evaluates all
         horizons, writes results.
      3. assemble_results.py aggregates all per-model outputs into
         unified comparison tables.

  Key difference from main:
      Main: 8 standalone models, each self-contained with its own config
      and scripts.
      Integrate: Shared pipeline, 4 active models + 1 baseline, models
      excluded from pipeline remain as artifacts only.
